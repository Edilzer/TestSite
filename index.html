Cómo probar scraping aquí

  1. Para probar scraping estático, usa requests.get y parsea la tabla de usuarios o la lista de posts que están en el HTML inicial.
  2. Para probar scraping con ejecución de JS, usa Playwright o Selenium — la sección "Comentarios" se añade por JavaScript después de 2 segundos.
  3. El formulario de login incluye un campo oculto csrf_token y los nombres de los inputs son username y password. Esto permite practicar envíos simulados y técnicas de scraping que manejan sesiones (cookies).
  4. El botón "Cargar más" agrega más posts mediante JS (simula paginación dinámica). Para obtener esos datos con requests tendrás que conocer el endpoint — en este sitio está solo disponible si ejecutas JS.
